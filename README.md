# 🏦 Exercise Loan Report – Power BI Dashboard

## 📌 Project Overview
The **Exercise Loan Report** is an interactive dashboard developed using Microsoft Power BI to analyze loan applications, funded amounts, loan repayment activity, and borrower characteristics. It provides a consolidated view of loan performance through KPIs, charts, tables, and interactive filters.

## 🎯 Objectives
- Analyze overall loan application and funding performance.
- Compare good loans and bad loans based on loan metrics.
- Monitor interest rates, debt-to-income (DTI) ratios, and loan status.
- Understand loan distribution across purposes and employee experience.
- Enable data-driven insights through interactive visualizations.

## 📊 Key Performance Indicators (KPIs)
- **Total Funded Amount:** Total amount funded for approved loans.
- **Total Loan Applications:** Overall number of loan applications.
- **Total Amount Received:** Total amount received from borrowers.
- **Average Interest Rate:** Average interest rate across loans.
- **Average DTI:** Average debt-to-income ratio.

## 📈 Dashboard Highlights
- **Good vs. Bad Loan Analysis:** Compares loan applications, funded amounts, and amounts received.
- **Loan Status Analysis:** Displays loan performance by status and verification category.
- **Loan Purpose Analysis:** Shows the amount received across different loan purposes.
- **Employee Length Analysis:** Examines loan amounts received based on borrowers' employment length.
- **Interactive Filters:** Filter the report by state, purpose, grade, and sub-grade.

## 📄 Report Page
This report contains one page:

- **Exercise Loan Report:** Provides a consolidated overview of loan performance, borrower information, funding, repayments, and risk-related metrics.

## 🛠️ Tools & Technologies
- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **DAX (Data Analysis Expressions)** – KPI calculations and analytical measures.
- **Power Query** – Data cleaning and transformation.
- **Data Visualization** – Interactive charts, KPI cards, tables, and slicers.

## 💡 Key Benefits
- Simplifies loan performance monitoring.
- Helps identify trends in good and bad loans.
- Provides insights into repayment activity and borrower profiles.
- Supports analysis through dynamic filtering and visual reporting.

## 🚀 How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Refresh the data source if required.
4. Explore the **Exercise Loan Report** page using the available filters and visualizations.
