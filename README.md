# Exercise Loan Report – Power BI

An interactive Loan Report Dashboard developed using Microsoft Power BI to analyze loan applications, funded amounts, repayments, and borrower profiles.

## Key Features
- Total Loan Applications and Funded Amount
- Good vs. Bad Loan Analysis
- Average Interest Rate and DTI
- Loan Status and Verification Analysis
- Loan Amount Received by Purpose and Employee Length

## Report Page
- **Exercise Loan Report** – Interactive dashboard with KPI cards, charts, tables, and slicers.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
